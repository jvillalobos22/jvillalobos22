# Hi, I'm Juan 👋

Full-stack engineer at **IBM Consulting** (San Francisco), building enterprise-grade
software, most recently large-scale public-sector healthcare platforms. Lately I've
been focused on the next layer up: **making AI agents do real engineering work,
autonomously and to a high bar.**

### What I'm building now
- **Spec-driven multi-agent development**: I orchestrate sub-agents across the full
  delivery loop. Big stories get a rigorous spec-first workflow: structured specs,
  task decomposition, and parallel agents implementing changes that span many files
  and services. Simpler tasks and bug fixes go through lightweight, highly automated
  flows built to produce small, quick-to-review changes.
- **Taking myself out of the loop (safely)**: I keep refining my own skill library so
  agents handle more of the work on their own, while quality gates, security
  guardrails, and automated checks hold the bar where a human reviewer would.
- **Team-scale agent enablement**: I maintain our shared skill libraries for IBM Bob
  and IBM Consulting Advantage, bringing engineers onto my multi-agent workflows and
  giving non-technical teammates reusable skills for backlog grooming and ideation.
- **Daily driver**: [Orca](https://onorca.dev) as my agentic development environment,
  plus Claude Code heavily.

### What I care about
